# Contributing

PIA Bazzite is primarily developed and tested on Bazzite with KDE Plasma.

## Before opening an issue

- Run the built-in self-test.
- Check the live log for a readable error message.
- Confirm that NetworkManager and WireGuard are available.
- Remove passwords, PIA tokens, WireGuard private keys, and full public IP
  addresses from anything you post.

## Pull requests

Keep changes focused and preserve the following project rules:

- Never log credentials, tokens, or private keys.
- Never silently disable IPv6 permanently.
- Keep NetworkManager as the connection backend.
- Keep English as the default UI language.
- Add matching English and German translation keys.
- Prefer understandable user-facing errors over raw command output.
